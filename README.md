# TranslatePage

Extension cho Brave để dịch nội dung trang web sang tiếng Việt bằng AI (Gemini API).

## Cài đặt nhanh

1. Mở `brave://extensions/`
2. Bật **Developer mode**
3. Chọn **Load unpacked** và trỏ tới thư mục chứa file `manifest.json`

## Cách dùng

1. Bấm icon extension
2. Nhập Gemini API key
3. Bấm **Dịch trang sang tiếng Việt**
4. Extension sẽ gửi nội dung trang cho Gemini và thay nội dung trang bằng bản dịch tiếng Việt

## Ghi chú

- Extension đang gọi Gemini endpoint `v1beta` (`generateContent`) theo API hiện hành của Google AI Studio.
